## 📖 About
This is a modern, responsive single-page portfolio showcase website. It features smooth **scroll-triggered animations** and is built using semantic HTML5, clean CSS3 (with custom variables), and the modern JavaScript `IntersectionObserver` API.

It implements the task plan for building an animated portfolio with scroll-triggered effects and is visually styled with custom project cards.

### 🎯 Objective
* Set up HTML sections for each project entry
* Define CSS keyframes/transitions for fade-in and slide-up animations
* Use `IntersectionObserver` in JS to add animation classes when elements enter the viewport
* Add transition delays for a staggered effect
* Test on desktop and mobile for performance and responsiveness
